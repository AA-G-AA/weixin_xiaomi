# 我在校园+ 自动签到助手

基于 AutoJS 的安卓自动化脚本，可以实现小米手机每天自动完成“我在校园+”小程序的签到。

## ✨ 功能

- **自动唤醒屏幕并解锁**：定时执行脚本时，自动唤醒屏幕，滑动解锁后进入桌面
- **遍历桌面查找小程序**：从第一页开始，逐页滑动查找“我在校园 +”小程序快捷方式
- **自动进入小程序并签到**：找到小程序后自动点击进入，定位到当天的签到任务并完成签到
- **自动清理后台**：签到完成后回到桌面，清理最近任务，释放内存

## 📱 测试环境

- **手机型号**：红米 K30
- **脚本平台**：AutoX.js

## 🚀 使用方法

**创建桌面快捷方式**：**重要！** 运行前，务必先在微信中打开“我在校园+”小程序，点击右上角菜单 → “添加到桌面”，确保桌面上有这个快捷方式。
1. **安装 AutoXJS**：在手机上安装 AutoXJS 应用
2. **开启无障碍服务**：在手机设置 → 无障碍 → 已安装的服务中找到 AutoXJS，开启无障碍权限
3. **关闭电池优化**：在手机设置 → 电池 → 应用电池管理中，将 AutoXJS 设为“无限制”，防止后台被系统清理
4. **导入脚本**：将此脚本复制到 AutoXJS 的脚本目录中
5. **设置定时任务**：在 AutoXJS 中设置每天定时执行该脚本
6. **保持手机正常放置**：定时执行时手机会自动亮屏操作，注意不要遮挡屏幕

## ⚠️ 注意事项

- **屏幕尺寸适配**：清理后台的点击坐标(540, 2200)是写死的。如果该步骤不生效，请根据自己手机的屏幕分辨率，调整代码中靠近末尾 `click(540, 2200)` 的坐标数值。
- **锁屏密码**：该脚本仅支持滑动解锁，如果设置了密码/图案锁屏，可参考https://autoxjs.dayudada.com/v7/ 官方文档
- **小程序名称**：脚本默认查找“在校园 +”，如果名称不同，修改 `TARGET_TEXT` 变量值
- **电池优化**：建议将 AutoJS 加入电池优化白名单，防止后台被系统清理
